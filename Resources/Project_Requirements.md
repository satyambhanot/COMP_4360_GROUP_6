Project Description
• Aim of project:
• Explore an interesting machine learning problem
• Gain machine learning development experience
• See applications of theory covered in this course
• Read published machine learning papers

Project Requirements
• Select a published paper on machine learning
• Must be published in 2018 or later
• Must be from a Q1 journal or a top-tier conference
• Examples of Q1 journals are: JMLR, TPAMI, IJCV (list not exhaustive)
• Acceptable conferences include, but are not limited to:
• General ML/AI: NeurIPS, ICML, ICLR, AAAI, IJCAI
• Computer Vision: CVPR, ICCV, ECCV
• You can also use CORE A or CORE A* venues
• You can check the ranking of a venue using https://portal.core.edu.au/conf-ranks/
• arXiv does not count

Project Requirements
• Implement the model in the paper with the following requirements
• Domain Shift
• The model must be applied to a completely different domain
• e.g., if paper is about natural image segmentation, then you need to apply it to medical imaging
or satellite data, etc.
• Performance Audit
• Final submission must not just show that the model works
• You must present a sensitivity analysis or ablation study showing what happens when the model
breaks

Project Milestones and Deliverables
• Full Project Proposal
• Proposal must go beyond initial pitch and demonstrate technical feasibility
• Slides should include:
• Title Slide: Project name, group member names, course name, instructor’s name, and date
• Problem Domain & Dataset:
• Introduce the specific problem you are solving.
• Dataset: detailed description of your chosen dataset (size, resolution, file format, class distribution)
• You must explicitly confirm this is distinct from the dataset used in the original paper
• Source Paper & Methodology:
• Identify the specific paper (Title + Venue, 2018+) you are implementing.
• Architecture Diagram: A high-level diagram of the model architecture you will build

Project Milestones and Deliverables
• Full Project Proposal
• Slides should include:
• Adaptation Strategy:
• Explain the specific technical changes required to apply the paper's architecture to your new dataset.
• Examples: "We need to change the input channels from 3 (RGB) to 5 (Multispectral)," or "We must rewrite
the data loader to handle 3D volumes instead of 2D images.“
• Development Plan:
• Environment: State the framework (e.g., PyTorch) and hardware resources (e.g., Dept GPUs, Colab) you
will use
• Ablation Plan: Identify at least one "Ablation Study" you plan to perform (e.g., removing a specific module
or changing a hyperparameter to test robustness)
• Project Management:
• Gantt Chart: A timeline with clear milestones
• e.g., Data Pipeline Working, Baseline Training, Final Analysis

Project Milestones and Deliverables

• Role Division:
